# ЯП на которых будет вестись разработка

## Самая такая low level разработка будет исключительно на C и Assembly(конкретно NASM)

## Более высокоуровневая разработка:
 * старый добрый C
 * C++
 * Rust
 * Zig
 * D
 * ИСКЛЮЧЕНИЕ!!! GoLang т.к. у него есть сборщик мусора.

### Эти языки будут нужны для написания всего софта что идёт выше ядра, системы инициализации и системы старта бинарников. 
### К примеру dltsh, fpmcp, разные TUI утилиты и возможно они будут преобладать по количеству т.к. будут работать даже в TTY если тот же графический интерфейс отлетит по разным причинам. 
### Ну или мощностей на ПК конечного пользователя недостаточно для запуска полноценных приложений или даже граф. оболочки(правда это уже к пользователю вопрос почему у него Ogrizok 3000). 
### Потом после TUI утилит на этих ЯП будет идти написание как самой графической оболочки так и фреймворка для неё и полноценных приложений с интерфейсом.
### А дальше что только вздумается (на расте и с++ можно будет писать модули и патчи для ядра)

----------------------------

## Следующая категория это веб разработка. 
 
### Конкретно для backend будут только Golang или Rust. 
### Golang потому что подходит для этой сферы, а Rust если нужна скорость.
### Frontend же будет на самой обычной четвёрке: TS, JS, CSS(также ему подобные SCSS и т.д.) HTML. 
### На счёт библиотек или фреймворков для TS, JS я бы использовал Next JS. 

## Самая низшая каста это скрипты, буквально для чего угодно и это у нас будет целый набор:  
 * Bash(fish, zsh, nushell)
 * Python
 * Lua
 * Ruby
 * PowerShell (для подсистемы на Винду)
